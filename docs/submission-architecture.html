One checklist. Separate judgments.

Build a common judging aid once per question. Evaluate each answer against it, then join coverage to that answer’s own saved evidence.

  1. 1

    Save claim–citation judgments

    Check claims against their cited documents. Retain support labels, segment IDs and provenance so successful work can be reused.

    Full support 1Partial support 0.5Unsupported / uncertain 0
  2. 2

    Generate a shared reference + checklist

    The full question guides both outputs. Use pooled evidence excerpts when they fit; otherwise use exact-deduplicated validated claims with provenance.

    What goes into the reference?

    Fully supported claims can supply candidate facts. Partial claims remain flagged, non-citable guidance in the compact route—not fully established compound facts. There is no silent truncation.

    The reference obeys the question’s answer limit. The checklist and unresolved gaps are separate. This is an internal judging aid, not official gold.

    What makes a checklist item count?

    Each item has a factual/request kind and core/optional priority. Freeze one checklist for all answers. Accepted alternatives are sufficient routes, not extra obligations; missing optional details does not lower coverage.

  3. 3

    Grade coverage only

    The grader sees the question, checklist and submitted answer segments. It does not see source documents or citation-support labels.

    Covered · Partial · MissingEach decision points to exact answer segment IDs
  4. 4

    Join coverage to own-citation support

    Code joins those segment IDs to saved citation judgments. When needed, a bounded alignment resolves which supported portion of a partial claim covers a factual item.

    Coverage is not the same as grounding. The original citation labels stay unchanged.

  5. 5

    Apply the track’s formula

    RAG combines request coverage, citation precision and recall. RAGTIME combines grounded factual coverage and top-citation support. Retain the components and intermediate judgments for audit.

E = mean of two components

Grounded factual coverage
Factual-core checklist items supported by the answer’s own evidence
Top-citation sentence support
